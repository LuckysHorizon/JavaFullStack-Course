# CSS3 Exercises

Pure CSS layouts and styling exercises  no Bootstrap or JavaScript used (except the navbar checkbox hack, which is pure CSS).

## Exercises

| # | Exercise | Key Concepts |
|---|----------|-------------|
| 1 | dashboard/ | CSS Grid layout, dark theme, responsive sidebar |
| 2 | card-layouts/ | Image/profile/product cards, hover effects, auto-fit grid |
| 3 | pricing-section/ | Glassmorphism cards, responsive 3-tier pricing |
| 4 | animated-buttons/ | Gradient, outline, glow, ripple, loading animations |
| 5 | responsive-navbar/ | CSS-only hamburger (checkbox hack), dropdown menus |
| 6 | multi-column/ | CSS columns, drop cap, pull quotes, CSS Grid alt |
| 7 | form-styling/ | Custom checkboxes, radios, toggles, floating labels |

## How to Run

Open any index.html directly in a browser. No build tools needed.
