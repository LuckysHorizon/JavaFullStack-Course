# Bootstrap 5 Exercises  Module 1

A collection of **7 hands-on Bootstrap 5 exercises** designed to practice responsive layout, components, utilities, and interactivity using Bootstrap 5.3.3.

## CDN Used

All exercises load Bootstrap via CDN  no local installation required.

| Resource | URL |
|----------|-----|
| Bootstrap CSS | https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css |
| Bootstrap JS Bundle | https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js |
| Bootstrap Icons | https://cdn.jsdelivr.net/npm/bootstrap-icons@1.11.3/font/bootstrap-icons.min.css |

## How to Open

Simply open any index.html file in a modern web browser (Chrome, Firefox, Edge). No build tools or server needed.

## Exercises

| # | Folder | Description |
|---|--------|-------------|
| 1 | portfolio/ | Personal portfolio site with navbar, hero, about, skills, projects, and contact sections |
| 2 | admin-panel/ | Responsive admin dashboard with offcanvas sidebar, stat cards, and data table |
| 3 | product-cards/ | E-commerce product card grid with badges, ratings, and hover effects |
| 4 | navbar-demo/ | Navbar showcase with collapse, dropdowns, search, and multiple variants |
| 5 | carousel/ | Image carousel with captions, indicators, controls, and feature highlights |
| 6 | modal-form/ | Contact form inside a modal with Bootstrap validation and confirmation flow |
| 7 | pricing-table/ | 3-tier responsive pricing cards with feature comparison |

## Key Concepts Practiced

- **Grid System**: 12-column layout with container, row, col-* classes
- **Responsive Breakpoints**: col-sm-*, col-md-*, col-lg-* for adaptive layouts
- **Components**: Navbar, Cards, Modal, Carousel, Offcanvas, Tables, Badges, Progress Bars
- **Utilities**: Spacing (m-*, p-*), Flexbox (d-flex, justify-content-*), Colors (bg-*, text-*), Display (d-none, d-lg-block)
- **Forms & Validation**: Bootstrap form controls with was-validated and feedback classes
- **Icons**: Bootstrap Icons via CDN for UI elements

## Browser Support

Tested with Bootstrap 5.3.3  supports all modern evergreen browsers.
