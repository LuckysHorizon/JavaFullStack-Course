Array Methods Showcase

Explore JavaScript array methods with interactive examples using a student dataset.

Dataset Preview

map()

Transform student objects into display strings

students.map(s => ${s.name} (GPA: ${s.gpa}))

filter()

Find students with GPA greater than 3.5

students.filter(s => s.gpa > 3.5)

reduce()

Calculate the average GPA across all students

students.reduce((sum, s) => sum + s.gpa, 0) / students.length

find()

Find a specific student by name

students.find(s => s.name === 'Priya Sharma')

some() / every()

Check conditions across the dataset

some(s => s.gpa === 4.0) | every(s => s.age >= 18)

sort()

Sort students by GPA (descending)

[...students].sort((a, b) => b.gpa - a.gpa)

Method Chaining

Chain multiple methods: filter honor roll students, sort by GPA, and extract names

students.filter(s => s.gpa >= 3.5).sort((a,b) => b.gpa - a.gpa).map(s => s.name)
