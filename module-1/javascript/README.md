# JavaScript Exercises

Interactive JavaScript projects demonstrating DOM manipulation, async patterns, Fetch API usage, and CRUD operations.

## Projects

| # | Project | Key Concepts |
|---|---------|-------------|
| 1 | todo-app/ | LocalStorage, class/module pattern, filtering |
| 2 | weather-app/ | Fetch API, async/await, error handling |
| 3 | form-validator/ | Validation rules engine, password strength |
| 4 | calculator/ | Keyboard events, expression parsing, edge cases |
| 5 | dom-exercises/ | Element creation, style manipulation, traversal |
| 6 | array-methods/ | map, filter, reduce, find, sort, method chaining |
| 7 | async-examples/ | Promises, Promise.all, Promise.race, try/catch |
| 8 | crud-localstorage/ | Contact manager with full CRUD + search |

## How to Run

Open any project's index.html in a browser. Check the DevTools console for additional output.

> **Weather App:** You'll need a free API key from [OpenWeatherMap](https://openweathermap.org/api). Replace the placeholder key in app.js.
