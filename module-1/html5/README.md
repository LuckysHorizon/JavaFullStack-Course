# HTML5 Exercises

A collection of HTML5 exercises covering semantic markup, forms, browser APIs, and DOM interaction.

## Exercises

| # | Exercise | Key Concepts |
|---|----------|-------------|
| 1 | portfolio/ | Semantic tags, heading hierarchy, accessibility |
| 2 | registration-form/ | Form inputs, fieldsets, validation attributes |
| 3 | semantic-landing/ | Landing page with <article>, <figure>, responsive |
| 4 | multi-section-site/ | Smooth scroll navigation, active link tracking |
| 5 | event-handling/ | Click, hover, keypress, delegation, event object |
| 6 | form-validation/ | Real-time validation, password strength meter |
| 7 | web-storage/ | localStorage vs sessionStorage, data persistence |
| 8 | geolocation/ | Geolocation API, Haversine distance formula |
| 9 | dynamic-table/ | CRUD table, sorting, search, modal form |

## How to Run

Open any index.html file directly in a browser. No server or build step required.

> **Note:** The geolocation demo works best on localhost or HTTPS. Some browsers may block geolocation on file:// URLs.
